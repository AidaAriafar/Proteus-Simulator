پروژه ۹: ابزارهای اندازه‌گیری + D Flip-Flop

فایل‌ها:
- Project9.cpp
- CMakeLists.txt

قابلیت‌ها:
1) پروب ولتاژ قابل اتصال به GND، D، CLK، RESET، Q، QBAR و LOAD
2) ولت‌متر دیجیتال دو ترمیناله با انتخاب مستقل ترمینال مثبت و منفی
3) آمپرمتر دیجیتال برای جریان شاخه R-LED
4) اسیلوسکوپ ساده چهار کاناله برای D، CLK، Q و QBAR
5) D Flip-Flop لبه‌بالارونده با RESET ناهمزمان و تاخیر انتشار
6) کلاک خودکار یا پالس دستی
7) Run / Pause / Stop / Step / Next Event
8) سیم‌های رنگی: HIGH قرمز، LOW آبی، FLOAT زرد

کلیدها:
Space : Run/Pause
R     : Stop/Reset
S     : Step 0.05 s
N     : Next event
D     : Toggle D
C     : Manual clock pulse
A     : Auto clock on/off
X     : RESET on/off
P     : Next probe node
V     : Next voltmeter positive node
M     : Next voltmeter negative node
+/-   : Clock frequency

نکته ورودی D:
- کلیک چپ: تغییر LOW/HIGH
- کلیک راست: گردش LOW/HIGH/FLOAT
